# SVG Projection

This folder is the first concrete SVG projection layer for the architecture explorer described in Memo 1.

## Goal

The SVG view is used for architecture questions that are not naturally expressed as C4 boxes: state, lifecycle, transitions, region boundaries, and process flows.

## Intended usage

- keep Structurizr as the canonical architecture model;
- generate SVG projections from the same architecture knowledge;
- apply the Kami visual language through shared tokens;
- avoid forcing operational or lifecycle semantics into C4-only diagrams.
